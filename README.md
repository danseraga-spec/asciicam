# ASCII Cam

Android-камера, которая в реальном времени превращает картинку в ASCII-арт.
Фото, видео и GIF сохраняются в галерею, а текущий кадр можно скопировать как текст —
с готовым оформлением для Telegram, Discord, форумов и Markdown.

Автор: [Telegram-канал](https://t.me/eptahalflaif2)

## Возможности

- **Живое превью** в ASCII: 4 набора символов, 5 цветовых схем, плотность от 40 до 160 символов в строке.
- **Фото** — PNG в `Pictures/AsciiCam`.
- **Видео (MP4)** — в `Movies/AsciiCam`, кодируется аппаратным H.264-кодеком телефона.
- **GIF** — в `Pictures/AsciiCam`, до 20 секунд, собственный кодировщик без сторонних библиотек.
- **Копирование текста** с пресетами:
  - Telegram сообщение — блок кода ``` шириной 30 символов;
  - Telegram пост / подпись к фото — символами Брайля: они одной ширины в любом шрифте, поэтому арт не сползает даже там, где Telegram не поддерживает блок кода;
  - Discord, форум (BBCode), Markdown, Брайль, без форматирования.
- **Формат кадра**: полный экран, 16:9, 4:3, 1:1.
- **Зум** щипком и кнопками (0.6× / 1× / 2× / 5× / 10× — в зависимости от камеры), **фокус** тапом.
- **Чувствительность**: порог яркости, ниже которого клетка остаётся пустой.
- Автоконтраст, выбор разрешения камеры и ширины сохраняемых фото и видео.

## Управление

| Действие | Как |
|---|---|
| Сменить режим ФОТО / ВИДЕО / GIF | тап по названию или свайп влево-вправо |
| Снять / начать или остановить запись | кнопка спуска |
| Зум | щипок двумя пальцами или кнопки над режимами |
| Фокус | тап по картинке |
| Чувствительность | кнопка-солнце сверху |
| Формат кадра, плотность | кнопки в центре верхней панели |
| Скопировать текст | кнопка справа вверху |
| Открыть последний снимок | кружок слева от кнопки спуска |

## Сборка

Нужен JDK 17 или 21 (подходит JBR 21 из Android Studio; Java 25 с Gradle 8.9 не работает).

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
Можно также открыть папку проекта в Android Studio и нажать Run.

Каждый push собирается в GitHub Actions — готовый APK лежит в артефактах сборки.

## Совместимость

- Android 5.0+ (minSdk 21). MP4 — с Android 6.0, на 5.x запись идёт в GIF.
- Камера через CameraX: разрешение подбирается под устройство.
- Сохранение в галерею: на Android 10+ без разрешений (MediaStore), на 9 и старше — с запросом доступа к памяти.
- Учитываются вырезы под камеру, жестовая навигация, складные телефоны и split-screen.
- Нет нативного кода — работает на ARM, ARM64 и x86.

## Устройство кода

| Файл | Что делает |
|---|---|
| `MainActivity.kt` | интерфейс, камера, жесты, запись, сохранение |
| `AsciiConverter.kt` | кадр камеры (яркость) → сетка символов |
| `AsciiRenderer.kt` | отрисовка сетки моноширинным шрифтом |
| `AsciiView.kt` | экран превью с выбранным форматом кадра |
| `CopyFormatter.kt` | пресеты копирования, ресемплинг, Брайль |
| `Mp4Recorder.kt` | запись MP4 через MediaCodec |
| `GifEncoder.kt`, `GifRecorder.kt` | запись GIF |
| `GallerySaver.kt` | сохранение в галерею |
| `SettingsSheet.kt`, `Settings.kt` | настройки |
